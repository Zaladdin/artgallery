# Интерактивный 3D-прототип

Это браузерный UX-прототип публичной части «Смотрителя». Он демонстрирует путь посетителя: поиск художника → виртуальная комната → перемещение → карточка работы → 2D-список.

Длина зала рассчитывается по числу работ, но никогда не бывает меньше 15 × 4 м. Десять импортированных JPG из коллекции занимают минимальный зал 15 × 4 м и распределяются по дальней стене и стене у входа; при росте экспозиции длинная сторона увеличивается. Камера посетителя делает только полные шаги по 1 м; стены и картины не двигаются и не поворачиваются вместе с обзором.

Для быстрой загрузки у каждой картины есть три браузерные версии: полноразмерная для карточки, 1024 px для 3D-сцены и 320 px для списка работ. Исходные файлы пользователя не изменяются.

Запуск без установки зависимостей (из корня проекта):

```powershell
node prototype/serve.js
```

Затем открыть `http://localhost:4173`.

Демонстрационный поиск: `Айтен`, `Шейдаева` или `Ayten Sheydayeva`.

Управление в зале: `↑`/`W` — шаг вперёд на 1 м, `↓`/`S` — назад, `←`/`A` и `→`/`D` — боковой шаг влево и вправо относительно взгляда. Мышью или пальцем можно осматриваться во все стороны, включая потолок и пол; `Q`/`E` поворачивают взгляд, `R`/`F` наклоняют его вверх и вниз с клавиатуры. Горизонтальный обзор полный — 360°, вертикальный обзор ограничен 80° в каждую сторону, чтобы камера не переворачивалась. При первом открытии зала браузер загружает закреплённую версию Three.js из CDN.

## Публикация на GitHub Pages

В корне проекта есть workflow `.github/workflows/deploy-pages.yml`. Он публикует папку `prototype` как статический сайт после каждого push в ветку `main`.

Для первой публикации создайте пустой репозиторий на GitHub. В его настройках откройте **Settings → Pages** и выберите источник **GitHub Actions**. Затем из корня проекта выполните:

```powershell
git init -b main
git add .
git commit -m "feat: publish virtual gallery"
git remote add origin https://github.com/<логин>/<репозиторий>.git
git push -u origin main
```

Для обычного project site адрес будет `https://<логин>.github.io/<репозиторий>/`; если репозиторий называется `<логин>.github.io`, сайт откроется по адресу `https://<логин>.github.io/`.

Это всё ещё MVP без backend и админки: дальше нужны хранилище сканов, база данных, загрузка исходников и редактор экспозиции.
