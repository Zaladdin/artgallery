# Интерактивный 3D-прототип

Это браузерный UX-прототип публичной части «Смотрителя». Он демонстрирует путь посетителя: поиск художника → виртуальная комната → перемещение → карточка работы → 2D-список.

Зал строится прямо в браузере из простой геометрии Three.js — без импортированной 3D-модели. Это светлая симметричная экспозиция: тёплые стены и потолок, деревянный пол, плинтусы, карниз и два ряда чёрных трековых светильников. Каждая головка трека повёрнута к своей картине.

Размер зала зависит от количества работ: минимум **25 × 8 × 3,5 м**; при большем количестве удлиняется 25-метровая сторона. Для нынешних 10 работ создаётся зал 25 × 8 м. Картины остаются отдельными JPG-файлами и равномерно закрепляются по пять на каждой длинной стене. Каждая точка крепления проверяется по настоящей процедурной стене, поэтому полотно не появляется в воздухе. Ползунок регулирует общий свет, а направленные прожекторы над полотнами остаются включёнными.

Для быстрой загрузки у каждой картины есть три браузерные версии: полноразмерная для карточки, 1024 px для 3D-сцены и 320 px для списка работ. Исходные файлы пользователя не изменяются.

Полная версия с админкой и постоянным хранением (Node.js 22.13+), из корня проекта:

```powershell
npm ci
npm start
```

Галерея: `http://127.0.0.1:4173/`. Админка: `http://127.0.0.1:4173/#/admin`. При первом входе задайте собственный пароль. Данные и оригиналы находятся в закрытой папке `.gallery-data`, исключённой из Git. Не удаляйте её: там находятся ваши выставки.

Только статический просмотр без серверной админки:

```powershell
node prototype/serve.js
```

Затем открыть `http://localhost:4173`.

Демонстрационный поиск: `Айтен`, `Шейдаева` или `Ayten Sheydayeva`.

Управление в зале: `↑`/`W` — плавный шаг вперёд на 1 м, `↓`/`S` — назад, `←`/`A` и `→`/`D` — боковой шаг влево и вправо относительно взгляда. Мышью или пальцем можно осматриваться во все стороны, включая потолок и пол; `Q`/`E` поворачивают взгляд, `R`/`F` наклоняют его вверх и вниз с клавиатуры. Круглая точка на полу перед картиной плавно переносит к ней и направляет взгляд на полотно; тот же переход доступен кнопкой «К точке» в списке работ. Горизонтальный обзор полный — 360°, вертикальный обзор ограничен 80° в каждую сторону, чтобы камера не переворачивалась. При включённой системной настройке уменьшения анимации шаг выполняется сразу.

## Публикация на GitHub Pages

В корне проекта есть workflow `.github/workflows/deploy-pages.yml`. Он публикует папку `prototype` как статический сайт после каждого push в ветку `main`.

Для первой публикации создайте пустой репозиторий на GitHub. В его настройках откройте **Settings → Pages** и выберите источник **GitHub Actions**. Затем из корня проекта выполните:

```powershell
git init -b main
git add .
git commit -m "feat: publish virtual gallery"
git remote add origin https://github.com/<логин>/<репозиторий>.git
git push -u origin main
```

Для обычного project site адрес будет `https://<логин>.github.io/<репозиторий>/`; если репозиторий называется `<логин>.github.io`, сайт откроется по адресу `https://<логин>.github.io/`.

Серверная админка, SQLite, обработка изображений и редактор порядка экспозиции реализованы. Для GitHub Pages нужен экспорт опубликованных выставок; этот хостинг сам не запускает API. См. `server/README.md` и `docs/product-status.md`. Публичный хостинг серверной версии ещё не настроен.
