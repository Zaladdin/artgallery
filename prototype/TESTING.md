# Проверки интерактивной галереи

Запуск: `python -m http.server 4173 --directory prototype` и открыть `http://localhost:4173`.

| ID | Сценарий | Ожидаемый результат |
| --- | --- | --- |
| T01 | Ввести `Айтен` в поиск | Появляется результат «Айтен Шейдаева»; `Enter` открывает её зал. |
| T02 | Нажать `↑` или `W` в зале | Камера делает ровно один метр вперёд; в панели меняется расстояние от входа на 1,0 м. |
| T03 | Нажать `←` / `→` или `A` / `D` | Камера делает полный шаг на 1 м влево или вправо относительно взгляда; направление взгляда не меняется. |
| T04 | Провести мышью по сцене во все стороны или нажать `Q` / `E`, `R` / `F` | Меняется только направление взгляда; координаты посетителя не меняются. Доступен полный горизонтальный обзор 360° и наклон до 80° вверх или вниз без переворота камеры. |
| T05 | Нажать на любую картину | Открывается диалог с увеличенным изображением и метаданными выбранной работы. |
| T06 | Нажать `Esc` в диалоге | Диалог закрывается, пользователь остаётся в той же точке обзора. |
| T07 | Открыть «Список работ» | Появляется 2D-каталог; выбор работы открывает ту же карточку. |
| T08 | Открыть страницу на ширине 375 px | Поиск, кнопки навигации и список работ доступны без горизонтальной прокрутки. |
| T09 | Открыть зал с клавиатуры | Интерактивные элементы имеют видимый фокус и понятные текстовые метки. |
| T10 | Дойти до стены и снова нажать `↑`, `←` или `→` | Шаг не выполняется, положение не меняется, а статус сообщает, с какой стороны стена. |
| T11 | Открыть зал с 10 импортированными JPG на ширине 1440 px | С первого взгляда читается светлый прямой зал 25 × 8 × 3,5 м: тёплые стены и потолок, деревянный пол, два трека вдоль стен. Все 10 JPG закреплены на стенах без колонн и дверей, по пять с каждой стороны. |
| T12 | Открыть «Список работ» | В панели отображаются 10 разных миниатюр JPG; кнопка сообщает, открыта ли панель, а клик по каждой работе открывает соответствующее полное изображение. |
| T13 | Открыть зал с отключённым кэшем DevTools и отфильтровать Network по `gallery-room.glb` | Запроса к `assets/rooms/gallery-room.glb` нет; сцена открывается без ошибок в Console и без ожидания большой 3D-модели. |
| T14 | Повернуть обзор к каждой длинной стене | У каждой картины виден свой трековый светильник, наклонённый к полотну, и свет падает на полотно. У рам, стен и пола нет отбрасываемых теней; картина остаётся на стене при любом повороте обзора. |
| T15 | Передвинуть ползунок «Общий свет в зале» на 0 % | Зал темнеет, но направленные прожекторы над полотнами остаются включёнными: их линзы и сами картины остаются различимыми. |
| T16 | Нажать «Вперёд» или клавишу `W` | Камера и метка на плане плавно проходят один метр примерно за 280 мс; повторная команда на время перехода игнорируется, фокус остаётся на кнопке, после завершения показывается новое положение. При системном `prefers-reduced-motion: reduce` шаг выполняется без анимации. |

## Контракт для следующей фазы: загрузка 2D-медиа

| ID | Сценарий | Ожидаемый результат |
| --- | --- | --- |
| M01 | Загрузить портретный JPG, квадратный PNG и горизонтальный HEIC | Для каждого файла создаются превью и браузерная версия; у всех трёх сохраняется исходное соотношение сторон. |
| M02 | Открыть опубликованную комнату с этими тремя форматами | В сцену не передаётся HEIC; 2D-полотна появляются в подходящих слотах без обрезания. |
| M03 | Загрузить повреждённый HEIC | Администратор видит понятную ошибку, работа остаётся черновиком и не может быть опубликована. |
