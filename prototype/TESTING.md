# Проверки интерактивной галереи

## Серверная версия

Запуск `npm start`, админка `http://127.0.0.1:4173/#/admin`. Изолированные API/SQLite/медиа/экспорт-проверки: `npm test`. Проверка настоящего HEIC дополнительно включается переменной `GALLERY_HEIC_FIXTURE` с путём к тестовому файлу (см. `server/README.md`). Проверки не меняют базу владельца.

Сквозной сценарий: первый пароль → новый художник → биография/варианты имени → загрузка JPG/PNG/HEIC → описание/размеры/права → сохранение → предпросмотр → публикация → поиск по варианту имени → каталог → увеличение → 3D-маршрут → ссылка на конкретную работу. После снятия с публикации художника нет в публичном API; загруженные изображения недоступны анонимно. Старые статические изображения существующей коллекции уже публичны и остаются в репозитории.

Проверить конфликт сохранения в двух вкладках, ошибку одного файла в пакете, повторный вход после окончания сессии, сохранение редактирования после ошибки публикации, отказ от ухода с несохранёнными изменениями. Проверить 390 px и настольный макет. Перечень выполненного и оставшегося: `docs/product-status.md`.

## Статическая версия

Запуск: `python -m http.server 4173 --directory prototype` и открыть `http://localhost:4173`.

## Контракт для следующей фазы: загрузка 2D-медиа

Каталог: переключить «3D-зал / Каталог», открыть работу из сетки и закрыть Escape — фокус возвращается на её карточку. После возврата в зал положение камеры сохраняется. При блокировке загрузки gallery-scene.js автоматически открывается каталог с сообщением; карточки и увеличение остаются доступны. Проверить на ширине 390 px отсутствие горизонтальной прокрутки страницы.

Просмотр деталей: открыть горизонтальную и вертикальную работу, увеличить до 150–400%, переместить изображение мышью или пальцем, сбросить до 100%. Проверить разворот карточки «На весь экран», возврат и закрытие Escape. На телефоне панель масштаба должна переноситься без горизонтального переполнения страницы. В зале координаты доступны после раскрытия «О зале».

| ID | Сценарий | Ожидаемый результат |
| --- | --- | --- |
| M01 | Загрузить портретный JPG, квадратный PNG и горизонтальный HEIC | Для каждого файла создаются превью и браузерная версия; у всех трёх сохраняется исходное соотношение сторон. |
