# Состояние продукта

## Реализовано локально

1. Админка: первый пароль, вход/выход, создание нескольких художников, профиль, биография, варианты имени; черновик, предпросмотр и публикация.
2. SQLite хранит данные, пароли в виде scrypt-хеша, сессии и ограничения запросов. Сохранённый черновик не меняет опубликованную выставку.
3. Загрузка JPG/PNG/HEIC, отдельные оригиналы, проверка размера/типа/разрешения, серверная обработка в рабочих потоках. Версии 2048/1024/320 px сохраняют пропорции. Подтверждение права на публикацию обязательно для новой публикации.
4. Редактор экспозиции: порядок и видимость работ, цвета стен и рам, автоматический размер помещения от 25 × 8 м, предпросмотр. Произвольного перетаскивания полотен по стене пока нет.
5. Поля реальных названий, годов, техники, размеров и биографии доступны. Неподтверждённые годы жизни удалены из стартовой коллекции; биография и названия должны заполняться владельцем по достоверным данным.
6. Светлый, менее контрастный пол; дополнительные панели света, плана и координат раскрываются по запросу. Главная показывает доступные выставки.
7. Поиск нескольких авторов, каталог/3D, увеличение до 400%, перетаскивание, карточка на весь экран страницы, ссылки на работы, последовательный маршрут и справка.
8. Серверные интеграционные проверки, сквозная проверка админки и публичного интерфейса в Edge, настольный и мобильный макеты. Есть экспорт опубликованных выставок для статического хостинга.

## Что требует владельца или отдельного этапа

- При первом открытии админки владелец выбирает пароль. В проекте нет заранее заданного пароля.
- Реальные названия, биография, подтверждённые даты, размеры и права. Приложение не придумывает эти сведения.
- Выбор серверного хостинга, домена и бюджета; HTTPS и Secure-cookie конфигурация, резервное копирование. Локальный сервер специально доступен только на этом компьютере. GitHub Pages не исполняет серверную часть.
- Проверка на настоящих iPhone/Android и слабых устройствах; текущие мобильные проверки выполнены эмуляцией ширины в Edge. Производительность на реальных телефонах не измерена.
- Портрет автора, произвольная расстановка на стене, аудиогид, продажи и аккаунты художников не реализованы.
- Файлы старой статической коллекции, уже бывшие публичными в GitHub, нельзя отозвать из чужих копий. Снятие новой выставки блокирует публичную выдачу её загруженных изображений на локальном API.

Подробности запуска, хранения и экспорта — в `server/README.md`.
