# Онлайн-админка на Supabase Free

Настройки сайта содержат только публичный URL и publishable key. Не сохраняйте пароль базы, `service_role` или `sb_secret_…` в файлы сайта, GitHub или переписку.

1. Используйте отдельный проект только для галереи. В панели Supabase откройте **SQL Editor → New query**. Скопируйте содержимое `supabase/migrations/202611070001_gallery.sql` и нажмите **Run**. Это создаёт отдельные таблицы черновиков и публикаций, ограничения доступа и закрытые хранилища изображений. При ошибке не продолжайте, пока она не исправлена. Если проект уже использовался, проверьте существующие правила `storage.objects`: общие разрешающие правила могут открыть доступ к новым хранилищам.
2. В отдельном запросе выполните `supabase/seed.sql`. Он добавляет 10 уже опубликованных картин Айтен Шейдаевой. Если вы уже добавили её как художника в Supabase, скрипт не заменяет ваш черновик. Остальные локальные данные не переносятся автоматически.
3. Откройте **Authentication → Users → Add user → Create new user**. Введите собственный email и отдельный пароль для админки, подтвердите email в форме создания пользователя. Скопируйте **User UID** созданного пользователя.
4. В **SQL Editor** выполните следующий запрос, заменив `ВАШ_UID` точным UID. Это даёт право редактирования только этому аккаунту:

   ```sql
   insert into public.gallery_admins (user_id)
   values ('ВАШ_UID'::uuid)
   on conflict (user_id) do nothing;
   ```

5. В **Authentication** отключите **Allow new users to sign up** и убедитесь, что анонимный вход выключен. Вход существующего администратора по email и паролю останется доступен.
6. После запуска схемы и проверки доступа опубликуйте подготовленную версию сайта через GitHub Pages. Откройте `https://zaladdin.github.io/artgallery/#/admin`, войдите и проверьте загрузку тестового изображения в черновик. Посетители увидят работу только после публикации.

До публикации можно проверить облачный режим через статический локальный сервер (`$env:PORT=4180; node prototype/serve.js` в PowerShell), затем `http://127.0.0.1:4180/?backend=supabase#/admin`. Для обычной локальной админки с SQLite используется `npm start` без `?backend=supabase`.

Исходники и черновики закрыты. Подготовленные изображения раздаются по временным ссылкам. После снятия выставки новые ссылки перестают выдаваться; уже выданная ссылка может работать до окончания срока действия. Ранее опубликованные файлы стартовой коллекции уже входят в статическую историю GitHub.
