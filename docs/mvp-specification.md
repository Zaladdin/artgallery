# MVP — онлайн 3D-галерея картин

**Статус:** черновик для согласования  
**Версия:** 0.1  
**Цель:** администратор самостоятельно создаёт и публикует виртуальную комнату художника, а посетитель быстро находит её по имени и осматривает работы в браузере.

## 1. Граница первой версии

### Входит

- Поиск художника по ФИО и вариантам имени.
- Одна комната на художника, созданная на базе готового 3D-шаблона.
- До 20 картин в комнате; автоматическое распределение по слотам стен.
- Поворот обзора мышью, пальцем и клавиатурой; переходы между фиксированными точками обзора.
- Крупный просмотр и карточка каждой работы.
- Админка для создания художника, загрузки работ, предпросмотра и публикации.
- 2D-каталог работ, если 3D недоступен или пользователь его отключил.

### Не входит

- Свободное передвижение с физикой, аватары и VR.
- Несколько этажей и уникальная архитектура для каждого художника.
- Продажи, комментарии, личные кабинеты художников, аудиогиды и совместные туры.

> **Продуктовое решение:** навигация строится как Google Street View, а не как компьютерная игра. Это уменьшает время загрузки, риск укачивания и сложность поддержки на телефонах. Картины остаются 2D-сканами или фотографиями: 3D-сцена содержит только помещение, освещение, рамы и плоские поверхности, на которые без искажения накладываются изображения работ.

> **Визуальное направление первого шаблона:** прямоугольная светлая выставочная комната с видимыми полом, потолком, задней и двумя боковыми стенами. Работы висят на всех доступных стенах с перспективой, а не располагаются на плоском фоне.

## 2. Пользователи и сценарии

| Роль | Главная задача | Успешный результат |
| --- | --- | --- |
| Посетитель | Найти художника и познакомиться с работами | Открывает его зал, осматривается, читает карточки картин |
| Администратор | Создать и опубликовать экспозицию | Новый зал появляется в публичном поиске без участия разработчика |

### Основной путь посетителя

1. Открывает главную страницу.
2. Вводит ФИО или псевдоним художника.
3. Выбирает результат поиска.
4. Попадает в виртуальную комнату, вращает обзор и перемещается по точкам.
5. Нажимает на картину и открывает её изображение и описание.

### Основной путь администратора

1. Входит в защищённую админку.
2. Создаёт карточку художника.
3. Загружает сканы и метаданные работ.
4. Выбирает шаблон комнаты, проверяет расстановку в предпросмотре.
5. Публикует комнату.

## 3. Схема ключевых экранов

### Экран 1 — главная и поиск

```text
┌─────────────────────────────────────────────────────────────────────┐
│  Логотип                                             Войти (admin)  │
│                                                                     │
│                    [ фоновая сцена галереи ]                       │
│                                                                     │
│                 Найдите художника                                  │
│        [ Введите ФИО или псевдоним                    🔍 ]          │
│                                                                     │
│      Поиск ведёт непосредственно в виртуальные экспозиции.         │
└─────────────────────────────────────────────────────────────────────┘
```

- Фон — лёгкое изображение или минимальная анимированная сцена, не обязательный 3D-рендер.
- Результаты появляются под полем: портрет/заглушка, ФИО, годы жизни или деятельности, число работ.
- При пустом результате: предложение проверить написание; без тупикового экрана.

### Экран 2 — виртуальная комната

```text
┌─────────────────────────────────────────────────────────────────────┐
│ ← К поиску       Имя художника                     Список работ ☰ │
│                                                                     │
│                                                                     │
│                      [ 3D-зал и картины ]                          │
│                                                                     │
│                                                      ┌───┐          │
│                                                      │ ↑ │          │
│              Наведите на картину, чтобы узнать о ней │← →│          │
│                                                      │ ↓ │          │
│                                                      └───┘          │
│  ○ Точка 1  ● Точка 2  ○ Точка 3        ⛶ Полный экран  ? Помощь  │
└─────────────────────────────────────────────────────────────────────┘
```

- Основное действие — сама экспозиция; элементы интерфейса не должны её перекрывать.
- Перетаскивание меняет направление взгляда; колёсико/жест масштабирования не должно позволять «пройти сквозь стену».
- Стрелки на экране, клавиши `← ↑ → ↓`/`WASD` и доступные точки обзора делают путь очевидным.
- Ссылка «Список работ» открывает 2D-каталог и служит fallback-режимом.

### Экран 3 — работа крупно

```text
┌─────────────────────────────────────────────────────────────────────┐
│  × Закрыть                                                           │
│                                                                     │
│          [ адаптивное крупное изображение картины ]                 │
│                                                                     │
│  «Название», 1985                         Предыдущая  Следующая   │
│  Техника · Размеры                                                     │
│  Короткое описание / история работы                                  │
└─────────────────────────────────────────────────────────────────────┘
```

- Открывается поверх комнаты без потери текущей точки обзора.
- Изображение доступно для увеличения; метаданные читаются с клавиатуры и скринридером.

### Экран 4 — админка: создание комнаты

```text
┌─────────────────────────────────────────────────────────────────────┐
│ Админка / Художники / Новый художник                     Сохранить │
├──────────────────────────────┬──────────────────────────────────────┤
│ Данные художника             │ Комната                              │
│ [ФИО___________________]     │ [Превью шаблона и расстановки]       │
│ [Псевдонимы____________]     │                                      │
│ [Биография_____________]     │ [ Шаблон: Белый зал ▾ ]              │
├──────────────────────────────┼──────────────────────────────────────┤
│ Работы (12)                  │ Статус: Черновик                     │
│ [+ Загрузить]                │ [Предпросмотр] [Опубликовать]        │
│ • Название / обложка / статус│                                      │
└──────────────────────────────┴──────────────────────────────────────┘
```

- Единая форма вместо набора несвязанных экранов.
- У каждой работы есть статус обработки изображения, видимость и позиция в комнате.
- «Опубликовать» активно, только если завершена обработка изображений и заполнены обязательные поля.

## 4. Функциональные требования

### Публичная часть

1. Поиск не зависит от регистра и лишних пробелов; работает для кириллицы и латиницы.
2. Поиск учитывает ФИО и заданные администратором варианты имени.
3. В поиске видны только опубликованные художники.
4. В сцене загружаются подготовленные версии изображений, а не оригиналы.
5. Картина открывается по клику/касанию и с клавиатуры.
6. При недоступном WebGL автоматически показывается полноценный 2D-каталог.
7. Для картины сохраняются физические ширина и высота; в 3D она отображается плоской текстурой с исходным отношением сторон, без обрезания или растяжения.

### Админка

1. Доступна только пользователям с ролью `admin`.
2. Для художника хранятся: ФИО, URL-идентификатор, варианты имени, биография, портрет, статус публикации.
3. Для картины: название, год, техника, физические ширина и высота, описание, права на публикацию, порядок, ссылки на версии изображения.
4. Загрузка принимает JPG/JPEG, PNG и HEIC. Исходный файл остаётся приватным; после загрузки создаются превью, сценическая и полноэкранная браузерные версии.
5. HEIC обрабатывается сервером с учётом EXIF-поворота и профиля цвета. Посетитель получает совместимые WebP/AVIF или JPEG-версии, а не сам HEIC.
6. Авторасстановка определяет, является ли работа портретной, квадратной или горизонтальной, подбирает слот нужного типа и масштабирует её без обрезания. Администратор может менять порядок и закреплять картину за слотом.
7. Снятие с публикации немедленно убирает художника и его работы из поиска.

## 5. Данные и технические ограничения

| Сущность | Назначение |
| --- | --- |
| `artists` | профиль автора и настройки поиска |
| `artworks` | метаданные, физические размеры, статусы и версии 2D-изображений работ |
| `gallery_rooms` | художник, шаблон, статус черновика/публикации |
| `gallery_placements` | связь работы со слотом стены, масштабом и рамой |
| `viewpoints` | позиция камеры, направление взгляда и доступные переходы |

Для `artworks` отдельно хранятся `physical_width`, `physical_height`, `physical_unit`, `source_mime_type`, размеры исходного файла и состояние обработки. Отношение сторон для 3D берётся из физических размеров, а не растягивается под слот. В Three.js каждая работа — прямоугольная плоскость с 2D-текстурой; 3D-модель создаётся только для зала и, опционально, рамы.

Рекомендуемый стек: **Next.js + TypeScript**, **React Three Fiber / Three.js**, **PostgreSQL**, объектное хранилище и CDN для медиа. Оригиналы сканов должны оставаться непубличными; публичные размеры создаются серверной обработкой. Перед выбором сервиса обработки нужно проверить его гарантированную поддержку HEIC/HEIF в целевой среде.

## 6. Качество, доступность и безопасность

- Первый экран должен отображаться быстро; 3D-сцена и тяжёлые текстуры подгружаются после него.
- Интерфейс полностью управляется клавиатурой, имеет видимый фокус и текстовые альтернативы работ.
- На мобильном устройстве доступны touch-поворот, экранные стрелки и 2D-каталог.
- Загрузка принимает только проверенные типы файлов и ограничивает размер/разрешение.
- HEIC проходит отдельную проверку: при невозможности конвертации администратор видит ясную ошибку и не может опубликовать битое изображение.
- Соотношение сторон сохраняется на каждом шаге обработки: ни одна работа не обрезается автоматически.
- Для каждой работы обязательна отметка о праве на публикацию; работа может быть быстро снята с показа.
- Следим за ошибками обработки изображений, недоступным WebGL и отсутствующими файлами.

## 7. Критерии готовности MVP

- [ ] Администратор публикует зал с 1–20 работами без вмешательства разработчика.
- [ ] Посетитель находит опубликованного художника по ФИО или псевдониму.
- [ ] Комната работает мышью, touch, клавиатурой и экранными стрелками.
- [ ] Все картины имеют крупный просмотр и метаданные.
- [ ] Неопубликованные материалы недоступны публично.
- [ ] Без WebGL открывается 2D-каталог без потери информации.
- [ ] В тестовом наборе с тремя художниками и 10–20 работами на каждого нет зависаний на среднем ноутбуке и современном телефоне.

## 8. Решения, ожидающие подтверждения

1. Первый визуальный стиль: белый современный зал, классический музей или авторское пространство.
2. Языки первой версии: русский или русский + английский.
3. Максимальное число работ в первом шаблоне.
4. Стартовый набор художников и сканов для демонстрации.
5. Кто подтверждает права на публикацию каждой работы.
